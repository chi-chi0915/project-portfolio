AI 활용 단계: 3단계
AI 활용 방식:

모션인식 온디바이스 추론: 
Wear OS에서 수집한 가속도/자이로(6채널) 센서 (ACCEL_X, ACCEL_Y, ACCEL_Z, GYRO_X, GYRO_Y, GYRO_Z)
데이터를 입력으로(10ms당 1번 1000ms 동안 총 길이 100) 1D CNN(Convolutional Neural Network) 추론

→ 모델을 Wear OS에 Asset으로 넣고 데이터 수집과 함께 동작을 분류하여 결과를 유니티의 게임 로직(공격, 방어, 스킬)과 연동

건강 데이터 분석: 
ChatGPT(OpenAI API)를 통해 사용자가 기록한 삼성헬스의 걸음수/수면/칼로리 데이터를 헬스 커넥터로 받아와
사용자의 주간 리포트를 제공하고 캐릭터가 친근하게 데일리 피드백을 제공합니다.

데이터 활용 단계: 3단계
데이터 활용:

모션인식 온디바이스 추론:
자체 수집:
팀원이 직접 착용하여 동작 라벨링된 센서 CSV를 수집(사용자별/동작별 폴더 구조)

전처리/샘플링 최적화:
1. timestamp 컬럼 제거 → 고정 길이(100) 로 패딩/트렁케이팅
2. 사용자별 train/test 분리(폴더 단위, 무작위 셔플)
3. CNN을 이용해 신호의 특징을 추출
4. train - test 셋을 번갈아가며 학습하는 k-fold 방식을 통해서 최적의 모델 선정 

모델 적용 단계: 2단계
모델 적용 방식:

커스텀 경량:
CNN(Conv1d-BN-MaxPool ×2 → Fully Connected) 직접 학습 (CrossEntropyLoss, Adam)

데이터 증강:
스마트워치에서 측정한 원시 센서 데이터를 슬라이딩 윈도우(WINDOW_SIZE=100, STRIDE=10) 방식으로 분할하여 여러 학습 샘플로 확장. 마지막 윈도우가 부족할 경우 패딩(PAD_VALUE=0)으로 보완하여 데이터 손실 없이 샘플 수를 늘림.

모바일 추론 형태:
TorchScript → Lite Interpreter(PTL) 로 변환하여 온디바이스 실행

서비스 연계성 단계: 3단계
서비스 연계성:

모션인식:
프로젝트의 메인인 게임의 진행에 필수적인 요소
반복적인 모션에도 높은 정확도(98%)로 판단되며 공격, 스킬, 몬스터 공격 방어 등에 사용됨

사용자의 헬스 케어 데이터를 이용해 자신의 생활 습관을 돌아보고 피드백을 받을 수 있음

ChatGPT 분석 결과를 주간 리포트/개인화 코칭으로 제공해 리텐션 및 행동 유도에 활용

경량화: 적용

모바일 최적화 파이프라인:
TorchScript → optimize_for_mobile → Lite(PTL) 빌드

모델/입력 경량화:
1D CNN 구조, 입력 길이 100 스텝 고정, 배치 전송


실행 최적화:

워치에서 짧은 측정 윈도우(예: 1초) 만 포그라운드 서비스로 수집 후 배치 전송

불필요한 네트워크 왕복 제거(온디바이스 추론)로 지연·배터리 소모 최소화
